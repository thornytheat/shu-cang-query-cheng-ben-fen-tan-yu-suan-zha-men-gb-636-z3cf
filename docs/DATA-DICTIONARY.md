# 数据字典 costsplit

## 1 金额

| 项 | 定义 |
|---|---|
| 存储 | 数据库里一律整数「分」（INTEGER）；页面和 CSV 展示为两位小数的「元」 |
| 计算 | 分量用 Decimal（6 位小数）累加，最后一次量化到分 |
| 舍入 | `ROUND_HALF_UP`，只在量化到分时发生一次 |
| 单价 | 扫描 0.0280 元/GB；白天时长 0.4200 元/小时；夜间时长 0.2100 元/小时；并发加价 0.1500 元/并发·小时 |
| 最低计费 | 单条查询 0.01 元，低于此值按 0.01 元计 |

## 2 扫描量

| 项 | 定义 |
|---|---|
| 原始 | `scan_size` + `scan_unit` 两列，原值逐字保留（`scan_raw`） |
| 单位表 | B / KB / MB / GB / TB / PB，1024 进制；`MiB`/`吉`/`吉字节` 等别名归一 |
| 版本 | 统一折算成 GB，保留 6 位小数（`scan_gb`） |
| 字节数 | 同时保留精确字节数字符串（`raw.scan_bytes`），超过 2^53 也逐位保形，禁止科学计数法 |

## 3 时间与分桶

| 项 | 定义 |
|---|---|
| 入库 | 一律 UTC ISO8601；`Z` 视为 UTC，无偏移按 `+08:00` 解释 |
| 展示 | Asia/Shanghai（+08:00），精确到分钟 |
| 小时桶 | 左闭右开 `[桶起点, 桶起点 + 1h)`；跨零点、跨日照物理时间续切 |
| 时段 | 夜间 = 本地 22:00–06:00（`[22, 24) ∪ [0, 6)`），其余为白天 |
| 时长 | `duration_s` 秒；换算小时保留 6 位小数 |

## 4 空值与哨兵

| 值 | 含义 |
|---|---|
| `null` | 字段缺失（列不存在） |
| 空串 | 有列但没填 |
| 哨兵 | `-` `--` `—` `N/A` `NULL` `未知` `无` `暂无` `待定` 等，清单在 `app/config.py` 的 `SENTINELS` |
| 处理 | 扫描量、时长为哨兵 → 整行隔离（`Q_SENTINEL`）；并发、收益分为哨兵 → 取默认值 1 / 0 |

## 5 去重键与批次键

| 键 | 定义 |
|---|---|
| 行签名 | 原始行所有字段去空白后的元组；完全相同只保留文件中第一条并计「去重行」 |
| 冲突 | 同一 `query_id` 出现多个不同签名 → 整组隔离（`Q_DUP_CONFLICT`），不猜哪条为准 |
| 批次键 | `sha256(来源文件名 + 输入 sha256 + 预算 sha256 + 规则版本 + 评估日)` 取前 32 位 |
| 批次号 | `CS-{yyyymmdd}-{4 位序号}`，末位附 mod-11 校验位；`X` 表示余数 10 |

## 6 分摊

| 项 | 定义 |
|---|---|
| 独占 | 无 `shared_with` 的查询，成本全额归属 `dept` |
| 共享权重 | 部门时长(小时) × 部门扫描量(GB)，同一部门多条权重先合并 |
| 份额 | 按权重占比取整数分，最大余额法补齐差额；余额相同按部门名排序定序 |
| 未分摊 | 共享查询的权重合计为 0 时，成本进「未分摊」，不摊给任何部门 |

## 7 闸门

| 项 | 定义 |
|---|---|
| 排序 | 收益分 ÷ 成本(元) 降序；相同则按 `query_id` 升序 |
| 放行 | 累计成本 + 本条成本 ≤ 部门预算则保留，预算区间为 `(0, budget]`（等于预算仍保留） |
| 截断 | 放不下的计「被截断」，不占预算；部门账仍满足 分摊 = 保留 + 截断 |
| 无预算 | 预算表没有该部门 → 全部 `NO_BUDGET`，计入截断侧并给提示码 |

## 8 空态

| 情况 | 结论 |
|---|---|
| 仅表头 | `empty_state=ONLY_HEADER`，批次完成，合计 0 |
| 有行但字段全空 | `empty_state=ALL_EMPTY`，空行单独计数 |
| 无表头 / 0 字节 | 拒绝：`E_NO_HEADER` / `E_EMPTY_FILE`（422） |

## 9 申诉与版本

| 项 | 定义 |
|---|---|
| 可改字段 | `APPEAL_FIX_FIELDS`：归属部门、开始时间、时长、扫描量、扫描单位；其余字段（并发、收益分）要重新导入 |
| 单位约束 | 只改单位不改扫描量会让同一个数换义，直接拒（`Q_APPEAL_BAD_FIX`） |
| 改判依据 | 一次申诉只改登记的字段；查询不在本批、部门为空、数值解析不了都在解析阶段拒 |
| 同查询多条 | 改判内容相同 → 合并成一次（`Q_APPEAL_MERGED`）；改判目标不同 → 保留最早一条，其余记冲突（`Q_APPEAL_CONFLICT`） |
| 时段复核 | 改判后按小时桶重切一遍（左闭右开、跨日续切），桶内时长合计与金额要和计费一致，否则拒（`Q_APPEAL_BUCKET`） |
| 边界 | 本地 22:00 归夜价（含起点），06:00 归日价（夜间终点不含） |
| 重算 | 改判后的行重新计价 → 重新分摊 → 重新跑闸门；成本随归属部门变化（大客户折扣按部门整批扫描量判定） |
| 版本 | 每次结论变化写一个新版本，版本号只增不减；回滚按旧快照写成新版本，旧版本快照不被修改 |
| 快照 | 每次导入、闸门重算、申诉、回滚各留一份 depts/gates/shares/totals/账单成本，回滚只认这些快照 |
| 并发 | 提交带 `expected_version`，落后返回 409 `Q_STALE_VERSION`，不覆盖别人的结论 |
